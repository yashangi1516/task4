1. Clone or download the project files.
2. Ensure all files (`index.html`, `style.css`, and image file) are placed in the same directory.
3. Open the project folder in any code editor such as VS Code.
4. Run the `index.html` file using a web browser.
5. The webpage will display a centered image with a styled gradient button.
6. The project follows all assignment constraints and uses external CSS styling.
