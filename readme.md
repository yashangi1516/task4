# Image Button Webpage

## Project Description
This project is a simple webpage created using HTML and CSS.  
It displays an image and a button with gradient styling.

---

## Files Used

- index.html
- style.css
- image(3).jpg

All files are placed in the same directory.

---

## HTML Features

- Proper HTML document structure
- External CSS linked using `<link>`
- Image inserted using `<img>`
- Button added for user interaction

---

## CSS Features

- Used viewport units (`vw`, `vh`)
- Equal left and right spacing of 25%
- Top and bottom spacing of 10%
- Gradient background for button
- Box sizing applied using `box-sizing: border-box`
- Page fits screen without scrolling

---

## Restrictions Followed

- No Flexbox used
- No `overflow: hidden`
- No `position: relative`
- No `position: absolute`

---

## How to Run

1. Place all files in the same folder
2. Open `index.html` in any web browser

---

## Output

The webpage displays:
- A centered image
- A gradient button below the image
- Proper spacing and alignment
